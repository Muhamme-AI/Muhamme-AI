## Featured Projects

Every one of these is a working system rather than a notebook: an API, a UI, retrieval grounded in real data, and a path to deploy.

### 🥇 [Nexhost — Restaurant Operations AI Platform](https://github.com/Muhamme-AI/nexhost-platform-case-study)

The NEX platform I architected at Nexhost AI: TypeScript and React on the front end, Python services, PostgreSQL, hybrid RAG and an MCP tool layer, deployed via Vercel and taken from zero to live production within weeks. An orchestrator with specialised sub-agents handles everything from inventory counting to staff rotas, improving inventory accuracy by around 30%, cutting food waste by around 25% and reducing scheduling time by around 70%.

The production code is private, so the repo is the sanitised architecture case study: system diagrams, the request lifecycle, the agent, RAG and MCP design, the computer-vision pipeline and the observability layer, plus a small runnable sample of the provider-failover and role-scoped tool patterns with tests and CI.

`TypeScript` `React` `Python` `Multi-agent` `RAG` `MCP` `Computer Vision` `PostgreSQL` `Supabase` `Vercel` `GitHub Actions`

---

### 🥈 [Sentinel — Real-Time Fraud Detection](https://github.com/Muhamme-AI/fraud-detection)

Credit-card fraud scoring with a LightGBM model behind a Flask and Socket.IO gateway, a React ops dashboard with a live threat map, and a FastAPI RAG analyst assistant that lets an analyst interrogate flagged transactions in plain English. It runs locally or on Railway with a seeded demo dataset, and the repo documents the evals, the design trade-offs and the admin screens.

`Python` `LightGBM` `Flask` `Socket.IO` `FastAPI` `RAG` `React` `TypeScript` `Railway`

---

### 🥉 [Stock Forecast — RAG Multi-Agent Advisor](https://github.com/Muhamme-AI/stock-forecast)

LSTM, BiLSTM and GRU models for short-horizon next-step price prediction, wrapped in a FastAPI and LangGraph product: Groq-backed agents, local Chroma retrieval and a React chart-and-advisor dashboard, so every forecast comes with the reasoning and the sources behind it.

`Python` `LSTM / GRU` `FastAPI` `LangGraph` `Groq` `Chroma` `RAG` `React`

---

### 🎖️ [News Trading Intelligence](https://github.com/Muhamme-AI/trading-view)

A GBP/USD news-trading platform that scrapes the economic calendar, measures how price historically reacted to each release, and exposes a grounded AI advisor with RAG, tools, memory and confidence guardrails on Groq or OpenAI, so trade guidance is backed by measured edge rather than opinion.

`Python` `RAG` `Agents` `Tools & Memory` `Guardrails` `Groq` `OpenAI`
